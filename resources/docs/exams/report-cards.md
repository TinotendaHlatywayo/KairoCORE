# Produce and publish report cards

Report cards are built from the marks you've captured, dressed with your school's remarks, then published and printed.

## 1. Generate reports

1. Open **Exams & Grading → Academic Reports**.
2. Click **Generate Reports** and choose the academic year, term and the class / stream. The system builds one report per student from their captured marks.

## 2. Add remarks

- **Class Teacher Remarks** and **Headmaster Remarks** can be added per report (there is an **Add Class Teacher Remarks** action for working through a class).
- **Per-Subject Remarks** attach a comment to each subject line.
- Competency ratings (the UNHU values) can be recorded per student where your school uses them.

## 3. Publish

Reports start **unpublished**. Review the marks and remarks, then click **Publish Report** on each row — or publish in bulk once you're satisfied. Published reports are what families see and what printing uses.

Need to fix something later? **Unpublish Report** reopens a report for editing.

## 4. Print

- **Print Report** on a single row prints one student's card.
- **Bulk Print** (or Print Selected) prints a whole class at once.
- **Print All Filtered** prints everything currently matching your table filters.

> Always spot-check one report before a bulk print — a wrong term setting is much cheaper to catch on one sheet than on two hundred.
