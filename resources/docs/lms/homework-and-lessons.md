# Set homework and run online lessons

The **LMS** module is where teachers publish work for their classes and learners receive it in their portal.

## Post homework

1. Open **LMS → Homework** and click **Create**.
2. Choose the **class stream** and **subject**.
3. Give the work a clear **title** and write the **description** — what to do, how it will be assessed, and anything to bring to class.
4. Set the **due date**.
5. Attach supporting material:
   - **File** — a worksheet, reading or template.
   - **YouTube link** — a recorded lesson or explainer.

Save, and the homework appears for every learner in that class stream. The table shows a **submissions count** per item so you can see engagement at a glance.

## The LMS hub

Open **LMS → Homework & Lessons** for the overview. The hub groups the homework you've set and links straight into the list — handy at the start of a week when you're planning what to assign.

## Good practice

- Write the **title** as the task, not the topic ("Exercise 4.2 — quadratic equations", not "Maths").
- Always set a **due date**; overdue work is easy to spot in the list.
- Attach the worksheet file rather than describing it — learners can then work offline.
- Use YouTube links for revision content, and keep descriptions short enough to read on a phone.

## Who sees what

Learners see homework for their own class stream and subject in their student portal. Teachers see everything they have set; school administrators can review all classes. Marking and report cards live under **Exams & Grading**, not here — see [Set up assessments and capture marks](/docs/exams/assessments-and-marks).
