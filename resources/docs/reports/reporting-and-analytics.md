# Build reports and explore analytics

**Reports & Intelligence** turns the data you already capture into answers. There are three levels: quick dashboard numbers, custom reports you build once and reuse, and an explorer for ad-hoc analysis.

## Dashboard

Open **Reports & Intelligence → Dashboard** for the school overview: enrolment, attendance, fee collection and other headline figures for the current period. Start here each morning to spot anything that needs attention.

## Reports hub

Open **Reports & Intelligence → Reports** for the hub that links the tools below and any saved report templates.

## Report Generator

Open **Reports & Intelligence → Reports → Report Generator**. Build a report from scratch:

1. **Report name** — and optionally save it as a reusable template.
2. **Data source** — one or more datasets (students, staff, finance, attendance, and so on).
3. **Columns** — choose the fields to include. Fields are labelled with their source dataset.
4. **Joins** — when you pick more than one dataset, define how the records relate.
5. **Filters** — narrow to a year group, term, date range or status.
6. **Calculations** — totals, averages and counts on numeric fields.
7. **Sort** — decide the order of rows.
8. **Chart** — choose a chart type where a visual summary helps.
9. **Output format**:
   - **PDF document** — formatted and signed, ready to file
   - **CSV spreadsheet** — raw rows for Excel or Sheets
   - **Excel workbook (.xls)** — for further editing
   - **JSON data** — for integrations and dashboards
   - **Print view** — opens the browser print dialog
   - **Clipboard (HTML)** — rich text for email and documents

Click **Generate** and the report is compiled and added to your library.

## Generated Reports

Open **Reports & Intelligence → Reports → Generated Reports** to see every report you've produced. Each row shows its **status** (Completed, Processing or Failed), **format**, **record count** and processing time.

- **Download** the finished file.
- **Verify** re-checks the report against the live source data — if data changed after compilation, the row tells you to regenerate.

## Analytics Explorer

Open **Reports & Intelligence → Reports → Analytics Explorer** for ad-hoc analysis: change dimensions and measures interactively without building a formal report. Use it to answer one-off questions ("which streams have the lowest attendance this term?") before committing to a saved report.

> Save a report as a template when you know you'll run it every term — next time it's one click, with consistent columns and filters.
