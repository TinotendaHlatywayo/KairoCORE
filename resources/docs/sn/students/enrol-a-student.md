# Nyoresa mudzidzi zvakananga

Shandisa izvi kana mudzidzi achinge ajoinha asina kuenda nepamhepo application - semuenzaniso kunyoresa-mukati kana yepakati-temu kutamiswa.

## Usati watanga

Unoda **gore redzidzo** uye ingangoita imwe **fomu kana giredhi** (kosi) yakatogadzirwa. Ona [Academic setup](/docs/academics/academic-structure).

## Matanho

1. Vhura **Vadzidzi → Vadzidzi** munzvimbo yebasa yepadivi.
2. Dzvanya **Gadzira**.
3. Nyora zvizere zvemudzidzi: mazita, murume kana mukadzi, zuva rekuzvarwa, uye ruzivo rwekudhumana.
4. Muchikamu chekunyoresa chefomu rimwechete, sarudza:
- **Gore Redzidzo**
- **Form / Giredhi (Level)**
- **Kuyerera / Kirasi** - iyo rondedzero mafirita kune hova dzefomu rawasarudza.
5. Sevha.

Mudzidzi zvino anoonekwa mutafura yevadzidzi negore ravo razvino redzidzo, fomu uye rwizi rwunoratidzwa parekodhi yavo.

## Mubereki / mudzidzi portal account

Kana iwe waisa email kero yemudzidzi, sisitimu inongogadzira iyo portal account uye inotumira maemail chinongedzo chekusimudzira. Kana iwe wakasiya iyo email isina chinhu, hapana portal account inogadzirwa - iwe uchaona yambiro mushure mekuchengetedza ichikuudza izvo chaizvo. Unogona kuwedzera email gare gare nekugadzirisa mudzidzi.
