# Gadzira uye prinda makadhi eID evadzidzi

Zvitupa zvemudzidzi zvakagadzirirwa munzvimbo yekushandira uye anodhindwa pazvinodiwa - makadhi ega kana akawanda anomhanya.

## 1. Gadzira template

1. Vhura **Vadzidzi → ID Kadhi Matemplate**.
2. Dzvanya **Gadzira** kugadzira template nyowani kadhi.
3. Sarudza iyo **inoshanda chinangwa cohort** uye **inoonekwa theme maitiro**.
4. Shandura zvinhu zvaunoda kudhindwa: musoro wechikoro, motto, logo, zvekutaura, mufananidzo wemufananidzo, zita remudzidzi, kirasi nhanho, nhamba yeID yechikoro, nhamba yekubvumidzwa (yakadzima), zuva rekupera, QR kodhi uye barcode.
5. Wedzera motto yechikoro yetsika kana yemashure watermark mufananidzo kana iwe uchida imwe.
6. Sevha template.

Unogona kuchengeta matemplate akati wandei - semuenzaniso kadhi remudzidzi wezuva uye kadhi rebhodhi - uye sarudza kuti ndeipi yekushandisa panguva yekudhinda.

## 2. Dhinda kadhi remudzidzi mumwe chete

1. Vhura **Vadzidzi → Vadzidzi**.
2. Pamutsetse wemudzidzi, tinya **Printa ID**.
3. Kadhi rinodhinda rinovhura - tumira kune printa yako kana chengetedza sePDF.

## 3. Dhinda makadhi muhuwandu

1. Vhura **Vadzidzi → ID Kadhi Matemplate**.
2. Dzvanya **Makadhi Madhinda Akadhinda akawanda**.
3. Sarudza template uye cohort (fomu / giredhi kana rukova) yaunoda kudhindira.
4. Dhinda batch yakagadzirwa.

Iwe unogona zvakare kutara vadzidzi vakati wandei pa **Vadzidzi** tafura uye shandisa iyo yakawanda kudhinda chiito kudhinda iwo makadhi chete.

> Dhinda pakadhi stock pa100% chiyero (hapana "inokodzera peji") saka marongerwo anowirirana nemugadziri.
