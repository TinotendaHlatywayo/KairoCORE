# Rongedza chimiro chako chedzidzo

Usati wanyoresa vadzidzi kana kutora mamakisi, chimiro chechikoro chako chinofanira kuvapo. Zvese zviri munzvimbo yebasa - kunyoresa, matimetable, makadhi erepoti - anonongedza marekodhi aya.

Ese setup iri pazasi inoitika mu **Academics** chikamu chenzvimbo yebasa yepasidebar, pasi pe**Setup & Structure** boka.

## Order of operations

1. Gore rezvidzidzo (nematemu)
2. Mafomu / mamakisi (ane makirasi enzizi)
3. Zvidzidzo
4. Makirasi

Vagadzirire nenzira iyi - nhanho imwe neimwe inoreva marekodhi akagadzirwa pamberi payo.

## 1. Gore rezvidzidzo

Vhura **Zvidzidzo → Setup & Chimiro → Makore Edzidzo** uye gadzira gore razvino (semuenzaniso `2026`). Gore rega rega redzidzo rine mazwi kana masemesita aunodzidzisa. Vadzidzi vakanyoreswa *mugore rezvidzidzo, saka tanga warigadzira.

## 2. Mafomu kana mamakisi

Vhura **Academics → Setup & Structure → Level** uye gadzira makosi ako — aya anomiririra Mafomu kana Magiredhi (semuenzaniso Form 1, Form 2, Grade 7). Paunenge uchigadzira imwe, unogona kuwedzera yayo **kirasi hova** (semuenzaniso A uye B) zvakananga muchimiro chimwe chete uchishandisa hova inodzokorora.

## 3. Zvidzidzo

Vhura **Zvidzidzo → Setup & Chimiro → Zvidzidzo** uye wedzera zvidzidzo zvaunopihwa nechikoro chako (Masvomhu, Chirungu, Biology, zvichingodaro). Zvidzidzo zvinozobatanidzwa kuongororo uye makadhi emishumo.

## 4. Makirasi

Vhura **Dzidziso → Gadzirisa & Chimiro → Makirasi** uye wedzera makamuri emuviri (Lab 1, Vhara Kamuri 3). Makirasi anoshandiswa nematimetable uye kuronga.

Kana izvi zvavepo unogona kunyoresa vadzidzi, dhizaini ID makadhi, kuseta mafizi zvimiro, uye kutanga kutora bvunzo.
