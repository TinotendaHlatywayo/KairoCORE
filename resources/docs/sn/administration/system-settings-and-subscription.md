# Zvirongwa zveSystem uye kunyorera

Nzvimbo mbiri dzinodzora nzvimbo yekushanda pachayo: **System Administration** yemaitiro uye maitiro, uye **Kunyoreswa & Kubhadhara** yechirongwa chako.

## Zvirongwa zveSystem

Vhura **System Administration → System Settings**. Zvirongwa zvakaiswa muzvikamu:

### Branding

- **Theme & typography** - sarudza dingindira rechiratidzo, sarudza kuti rinoshanda kune yese nzvimbo yebasa kana mapeji ekusaina, uye woseta font (ine ratidziro mhenyu)
- **Mucherechedzo wechikoro** - rodha logo uye favicon, isa kureba kwelogo uye kupenya
- **Dashboard watermark** - rodha mufananidzo wekumashure uye udzore opacity uye kuyera

Shanduko dzinoshanda kunzvimbo yebasa, zvinyorwa zvinodhindwa uye portal, saka rodha logo yepamusoro-resolution.

### Module switch

Iwo mamodule anoonekwa mubhara reparutivi anogona kuvhurwa kana kuvharwa — semuenzaniso **Admissions & Online CRM**, **Students Directory**, **Academics & Curriculum**, mari, HR, inventory, library, boarding, hutano, kutaurirana, LMS, webhusaiti, mishumo uye manejimendi. Kudzima module kunoiviga nemamenu ayo echikoro chako pasina kudzima chero data.

Shandisa izvi kuchengetedza nzvimbo yebasa yakatarisa: chikoro chezuva chisina bhodhi hachidi mabhodhi eBoarding.

> Module switch inoshandura kufamba chete. Marekodhi aripo anoramba akasimba uye anozoonekwa zvakare kana iwe ukachinja module zvakare.

## Email kugadzirisa

Vhura **System Administration → System Settings → Email Configuration** kuseta zita remutumi nekero inoshandiswa kuita maemail, zviziviso uye password reset. Kuendesa bvunzo mushure mekuchinja kupi.

## Mushandisi manejimendi uye kuongorora

- **System Kutonga → Mushandisi Management** - maakaundi, mabasa uye madhipatimendi. Ona [Tonga maakaundi evashandi nemvumo](/docs/administration/staff-permissions).
- **System Administration → Odhita & Kutevedza → Audit Log** — ndiani akachinja chii, uye rinhi.
- **System Administration → Odhita & Kutevedzera → Kutengeswa Kwedhata** - kutumira kunze data rechikoro chako.

## Kunyoresa & kubhadhara

Vhura **Kunyoreswa & Kubhadharisa → Kunyoresa & Kubhadhara → Overview & Kubhadhara** kuona:

- hurongwa hwako hwazvino uye mangani **mazuva asara**
- **kiredhiti chechikwereti** - mari yekubhadhara mari yepamberi, inobviswa otomatiki pamazuva ekuvandudzwa
- zuva rinotevera rekubhadhara (kana kuti "Trial Active" paunenge uchiyedzwa)
- **invoice**, ine yakabhadharwa / isina kubhadharwa chimiro uye anodhawunirodha maPDF

Vandudza kuburikidza ne**Paynow** (EcoCash, OneMoney, ZimSwitch card, Visa/Mastercard) kana kurekodha dhipoziti kubhanga. **Kunyoreswa Kwangu** inoratidza zita rechirongwa, chimiro uye zuva rekupedzisira rekupera, ine chinongedzo kune yekubhadhara portal.

> Gadzirisa zuva rekupera risati rasvika kudzivirira kuvhiringwa kwevashandi nemhuri. Pamuyedzo, tarisa pakaunda yasara nemazuva padashboard.
