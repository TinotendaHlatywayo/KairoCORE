# Tonga maakaundi evashandi uye mvumo

Kupinda kwekutonga kune maviri akaturiki: **mushandisi maakaundi** (ndiani anogona kusaina) uye **mabasa** (zvavanogona kuona nekuita). Vese vari vaviri vanogara pasi pe **System Administration → Mushandisi Management**.

## 1. Gadzira maakaundi evashandi

Vhura **System Administration → User Management → User Accounts** uye wedzera mushandisi kune yega yega mushandi: zita, email, uye basa (ma) ravanofanira kubata. Mushandisi anogamuchira activation email uye anoseta yavo password.

Marekodhi evashandi akagadzirwa kuburikidza ne **HR & Payroll → Vashandi** vanopawo yakabatana portal account otomatiki.

## 2. Sarudza kubva kune akavakirwa-mukati mabasa

Ipuratifomu inotakura zvinonzwisisika zvisizvo (System Administrator, Chikoro Administrator, Teaching Staff, Accounts / Finance, HR, Health, Procurement, Librarian, Houseparent, Supporting Staff). Batanidza imwe kana kupfuura kumushandisi; yavo yeparutivi uye kugona kugadzirisa kuti ienderane.

## 3. Vaka basa retsika

Kana basa richida chaizvo chidimbu chimwe chekuwana:

1. Vhura **System Administration → User Management → Mabasa**.
2. Gadzira basa idzva woritumidza mushure mebasa racho (semuenzaniso "Giredhi 7 Coordinator").
3. Nyora chete zviwanikwa uye zviito zvinoda basa iri. Sevha, wozopa basa kumushandisi.

Mabasa echivanhu ndicho chishandiso chakakodzera kana mushandi achifanira kubata imwe nzvimbo zvakadzama asi asingaone imwe.

## 4. Madhipatimendi

Vhura **System Administration → User Management → Madhipatimendi** kutsanangura chimiro chevashandi vako. Madhipatimendi eboka revashandi vekubhadhara mubhadharo, kushuma uye muridzi wemukati wemarekodhi.

## Misimboti inochengetedza zvikoro

- **Ropafadzo shoma** - ipa izvo zvinoda basa, hapana chimwe.
- **Kupatsanura mari kubva kuvadzidzi** — mabhezari anowana mari; vadzidzisi vanowana mamakisi; vanhu vashoma vanoda zvose zvizere.
- **Ongorora pakuenda** - dzima account zuva rimwechete rinobva nemunhu; usadzima vashandisi vane marekodhi enhoroondo akabatanidzwa.

Kuti uwane wongororo yekuti ndiani akachinja chii, shandisa **System Administration → Odhita & Kutevedzera → Audit Log**.
