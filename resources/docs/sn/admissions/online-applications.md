# Gamuchira uye gadzirisa zvikumbiro zvepamhepo

Yese saiti yechikoro yakavakirwa pachikuva inosanganisira yeruzhinji **Nyorera Online** peji. Mhuri dzinotumira zvikumbiro ikoko; vashandi vako vanovaongorora munzvimbo yebasa.

## 1. Peji yeruzhinji yekushandisa

Pawebhusaiti yechikoro chako, peji rekubvuma rinogara pa`/apply-online`. Vanyoreri vanozadza ruzivo rwavo uye rodha magwaro aunoda, wobva waendesa.

Unogona kugadzirisa fomu rekubvuma uye magwaro anodiwa pasi pe **Admissions → Admission Settings** munzvimbo yebasa.

## 2. Ongorora zvikumbiro zvinopinda

1. Vhura **Kubvumidzwa → Zvishandiso** munzvimbo yebasa yepadivi.
2. Zvitsva zvekushandisa zvinoonekwa mune rondedzero ine chimiro chazvo.
3. Vhura application kuti uone kuzere kutumirwa uye magwaro akaiswa.

## 3. Bvuma mudzidzi

Kubva pane application unogona kubvuma mukwikwidzi. Kubvumirwa kunogadzira rekodhi yemudzidzi - mudzidzi anobva aoneka pasi pe **Vadzidzi** negore rezvidzidzo, fomu uye rwizi rwunotakurwa kubva pachikumbiro pazvinoshanda.

## 4. Invoice mari yacho

Kana wabvumirwa, chinja kuenda ku **Mari → Kubhadharira Mudzidzi & Mari Yemudzidzi → Mainvoice** uye gadzira inivhoisi (yega kana neinjini yekubhadharisa yega - ona [Invoicing](/docs/finance/fee-structures-and-invoicing)).

## Mamiriro ekushandisa iwe uchaona

Zvikumbiro zvinofamba kuburikidza nekutumirwa, pasi pekuongororwa uye kubvumidzwa (uye zvakarambwa pazvinenge zvakakodzera). Gara uchivhura rekodhi pane kuvimba nerunyoro rwemavara chete - iyo yakazara yakazara yekuona inoratidza zvese zvakatumirwa.
