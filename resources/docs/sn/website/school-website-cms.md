# Vaka uye shambadza webhusaiti yako yechikoro

Chikoro chese chiri papuratifomu chinowana webhusaiti yeruzhinji. Iyo **Webhusaiti** module ndiyo yemukati manejimendi system kumashure kwayo - hapana coding inodiwa.

## 1. Matemplate & kugadzira

Vhura **Webhusaiti → Matemplate & Dhizaini → Matemplate & Dhizaini** (iyo hub). Kubva pano unogona:

- **gadzira**, **duplicate** uye **bvisa** ane mazita saiti matemplate
- isa iyo **inoshanda template** yeyako saiti
- vhura iyo **Dhizaini Studio** yepamberi dhizaini basa
- vhura iyo **Mutariri Wemukati** kuti ugadzirise zvinotaurwa nesaiti

Iyo **Mawebhusaiti** tebhu inobata saiti rekodhi pachayo:

- **Template gallery** / **inoshanda template**
- **Font** uye **ekutanga / sekondari mavara**
- **SEO musoro suffix** - yakawedzerwa kumapeji mazita einjini dzekutsvaga

Sarudza template inoenderana nehunhu hwechikoro chako, wobva wagadzirisa mavara kumhando yako.

## 2. Mapeji

Vhura **Webhusaiti → Matemplate & Dhizaini → Mapeji**. Peji rega rega rine:

- **Title** uye **slug** — slug ikero yewebhu peji, saka ichengetedze ipfupi uye yakagadzikana
- **Yakadhindwa** shandura - mapeji asina kudhindwa akavanzwa kubva panzvimbo yeruzhinji
- **Homepeji** shandura - chaizvo peji rimwe chete rinofanirwa kunge riri iro rekutanga
- **Webhusaiti** — ndeipi saiti peji yacho

Shandisa **Visual Editor** pane peji kuronga zvirimo, kana kugadzirisa zvirimo kuburikidza neMutariri Wemukati.

## 3. Content

Vhura **Webhusaiti → Matemplate & Dhizaini → Mutariri Wemukati**. Inogadzirisa **zvidhinha zvemukati** mukati meiyo inoshanda template - misoro, zvinyorwa, mifananidzo, kudana-ku-chiito mavara uye kuunganidzwa kwemakadhi - uku dhizaini inoramba yakakiyiwa. Izvi zvinoreva kuti vashandi vanogona kugadzirisa meseji pasina kutyora marongero.

Isa mifananidzo yakananga kubva pachishandiso icho block inotarisira imwe.

## 4. Shambadzira

1. Ita shuwa kuti mapeji aurikuda ndee **Akatsikiswa**.
2. Simbisa kuti peji remba ramaka.
3. Tarisa saiti mubrowser - shandisa preview apo iripo, uye edza parunhare.

Peji rako rekubvumidzwa (`/apply-online`), ruzivo rwekufonera uye zviziviso zvese zvinogara pane ino saiti. Mhuri dzinosvika kubva kunotsvaga kana social media gara pano kutanga, saka chengeta mazuva enguva uye ruzivo rwekusangana ikozvino.

> Shandura iyo **slug** yepeji mhenyu chete kana iwe uchifanira - ekare zvinongedzo zvinomira kushanda. Sarudzo kugadzirisa musoro uye zvirimo.
