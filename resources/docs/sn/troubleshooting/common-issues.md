# Kugadzirisa matambudziko akajairika

Kurumidza kutarisa matambudziko anouya kazhinji. Kana chimwe chinhu pano chikasagadzirisa, bata rutsigiro kuburikidza nepuratifomu webhusaiti.

## Handikwanise kusaina

- Simbisa kuti uri paURL yepanzvimbo yebasa yechikoro chako (semuenzaniso `your-school.kairo.co.zw/workspace`), kwete kero yepuratifomu.
- Shandisa **Forgot password** pane peji rekupinda kuti uise patsva.
- Kana usati wambowana iyo activation email, tarisa spam, wobva wabvunza maneja kuti atumire zvakare kubva ku **System Administration → Mushandisi Management → Maakaundi emushandisi**.

## Mudzidzi haaoneke mumazita

- Tarisa tafura **mafirita** - fomu rasara kana gore sefa inovanza neimwe nzira-inofananidza vadzidzi.
- Tsvaga nenhamba yekubvumidzwa kana nhamba yeID yemudzidzi panzvimbo yezita (zviperengo zvinosiyana kupfuura zvaungafunga).
- Kana mudzidzi akabvumidzwa kuburikidza neMaapplication, simbisa iyo application yasvika yakatenderwa chimiro.

## Iyo auto-billing injini haina chayakagadzira

- Iva nechokwadi chokuti vadzidzi vane **kunyoresa** (gore rechikoro + fomu) - kunyoresa kubhadharisa, kwete mitsara yevadzidzi.
- Tarisa kuti **zvimiro zvekubhadhara** zviripo zvefomu iro uye gore rezvidzidzo.
- Kana ma invoice atovepo pachiyero ichocho uye achiri asina kubhadharwa, injini inosvetuka vadzidzi ivavo nechinangwa kudzivirira kubhadharisa kaviri.

## Mishumo yemakadhi anodhindwa aine mavanga asina chinhu

- Simbisa kuti **mamaki akatorwa** maringe neongororo yetemu iyoyo nechidzidzo.
- Simbisa kuti mareports **agadzirwa mushure mekunge** mamakisi aiswa - gadzira patsva kana mamaki asvika pave paya.
- Tarisa kuti uri kudhinda chaiyo **temu**.

## Maemail echiziviso haana kusvika

- Tarisa iyo **Delivery Channel** yaive **Email chete** kana **System neEmail**, kwete System chete.
- Simbisa kuti vateereri vanosanganisira vanogamuchira (basa-rinotariswa rinoenderana nekuchengetedza chaiko).
- Tarisa spam folder yechikoro; kumbira IT kuti ibvumire nzvimbo yekutumira yepuratifomu.

## Muripo uri painvoice isiriyo

- Rekodha mubhadharo chete kuburikidza ne**Rekodha Kubhadhara** painvoice mutsara — inochengeta masara uye marisiti zvakafanana.
- Kana mubhadharo wakatorwa uchipesana neinvoice isiriyo, bata rutsigiro pane kugadzirisa dhatabhesi - nhoroondo yekubhadhara inodyisa marisiti uye zvirevo.

## Mushandi CSV anopinza anoshuma kukanganisa

- Shandisa **Dhawunirodha Excel Template** patafura yeVashandi kuti mazita emakoramu aenderane chaizvo.
- **Zita rekutanga, Zita rekupedzisira, Email, Nhamba Yenhare, National ID uye Dhizaini** inodiwa.
- National ID ndiyo kiyi yekufananidza pakupinzazve kunze kwenyika: yakafanana ID yenyika inogadziridza mushandi aripo pane kugadzira duplicate. Chinja email kuti uvandudze.
- Vashandi vekondirakiti vanofanira kunge vaine **Zuva Rokupera Kwechibvumirano**.
- Gadzirisa mitsara yarambwa woisa iyo chete — ona [Import staff kubva paspredishiti](/docs/hr/importing-staff-from-spreadsheet).
