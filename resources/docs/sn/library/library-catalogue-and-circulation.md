# Mhanya raibhurari catalog uye kutenderera

Iyo **Raibhurari** module inovhara iyo catalogue, zvemagetsi zviwanikwa uye zuva nezuva kuburitsa uye kudzoka.

## Catalog

### Mabhuku

Vhura **Raibhurari → Catalog → Mabhuku**. Bhuku rekodhi rine:

- **Musoro**, **mudiki** uye **vanyori** (wedzera nhoroondo yemunyori mumutsara pazvinobatsira)
- **ISBN**, **muparidzi** uye **gore rekuburitsa**
- **Media mhando** uye **raibhurari fomati**
- **Chikamu** (gadzira zvikamu mukati)
- **Mufananidzo wekuvhara**
- **Makopi** — wedzera akati wandei emakopi chaiwo paunenge uchigadzira bhuku

Kopi yega yega chinhu chakasiyana chine chimiro chayo, saka makopi maviri emusoro mumwe chete anogona kubuditswa kuvaverengi vakasiyana. Chengetedza **makopi** chikamu chiripo: kopi yakarasika inofanirwa kumakwa, kwete kubviswa chinyararire.

### eResources

Vhura **Raibhurari → Catalog → eResources** yezvinyorwa zvedhijitari. E-resource yega yega ine zita, media media, fomati, chikamu, vanyori uye **yekuona link**. Iwe unodzora kana vaverengi vachigona **kuona** iyo sosi, **kudhawunirodha** iyo, kana zvese, uye kana kudhawunirodha kwakawanda kuchitenderwa.

## Kutenderera

### Ipa bhuku

Vhura **Raibhurari → Kutenderera → Bhuku Rezvinyorwa**. Iyo peji inokufambisa iwe kuburikidza:

1. **Sarudza bhuku** (tsvaga nemusoro kana ISBN).
2. **Sarudza kopi** — makopi akanyorwa kuti *aripo* anogona kupihwa.
3. **Sarudza mugamuchiri** — mudzidzi kana mushandi.
4. Seta iyo **yekudzoka zuva** (default kusvika kumazuva gumi nemana).

Simbisa, uye chimiro chekopi chinoshanduka kuita *chakabudiswa*. Muverengi anoona chikwereti mune yavo portal.

### Nyaya nekudzoka

Vhura **Raibhurari → Kutenderera → Nyaya** kuti uone chikwereti chese nebhuku rayo, kopi, mugamuchiri, zuva rekuburitsa, zuva rekubhadhara uye chimiro. Shandisa ku:

- tsvaga **zvikwereti zvakapfuura** zvikwereti - sefa nenguva yakafanira
- **dzorera** kopi kana bhuku radzoka (kopi inowanika zvakare)
- tarisa nhoroondo yekukwereta yemuverengi

> Skena bhakodhi rekopi padhesiki paunenge uchiburitsa nekudzoka - inokurumidza kupfuura kutsvaga uye inodzivirira kuburitsa kopi isiriyo.

## Zivo

Boka re**Ruzivo** rinochengeta zvechikoro chako chega zvinyorwa:

- **Knowledge Assets** — magwaro, marongero, mapepa ekare nemadhairekitori
- **Galleries** - mifananidzo kuunganidzwa kwezviitiko, kambasi uye kushambadzira

Izvi zvinotsvakwa nevashandi uye zvinogona kugoverwa nenharaunda yechikoro zvichienderana nemagadzirirwo avo.
