# Design and print student ID cards

Student identity cards are designed in the workspace and printed on demand — single cards or bulk runs.

## 1. Design a template

1. Open **Students → ID Card Designer**.
2. Create a new card template and lay it out with your school logo, colours, and the fields you want printed (name, student ID, form, photo, and so on).
3. Save the template.

You can keep several templates — for example a day-scholar card and a boarding card — and choose which one to use at print time.

## 2. Print one student's card

1. Open **Students**.
2. On the student's row, click **Print ID**.
3. The printable card opens — send it to your printer or save it as a PDF.

## 3. Print cards in bulk

1. Open **Students → ID Card Designer**.
2. Click **Bulk Print ID Cards**.
3. Choose the template and the cohort (form / grade or stream) you want to print for.
4. Print the generated batch.

> Print on card stock at 100% scale (no "fit to page") so the layout matches the designer.
