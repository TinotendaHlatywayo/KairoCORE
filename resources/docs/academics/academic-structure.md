# Set up your academic structure

Before you enrol students or capture marks, your school's academic structure must exist. Everything in the workspace — enrolments, timetables, report cards — references these records.

All of the setup below happens in the **Academics** section of the workspace sidebar, under the **Setup & Structure** group.

## Order of operations

1. Academic year (with terms)
2. Forms / grades (with class streams)
3. Subjects
4. Classrooms

Create them in this order — each step references the records created before it.

## 1. Academic year

Open **Academics → Setup & Structure → Academic Years** and create the current year (for example `2026`). Each academic year contains the terms or semesters you teach. Students are enrolled *into* an academic year, so create it first.

## 2. Forms or grades

Open **Academics → Setup & Structure → Level** and create your courses — these represent Forms or Grades (for example Form 1, Form 2, Grade 7). While creating one, you can add its **class streams** (for example A and B) directly in the same form using the streams repeater.

## 3. Subjects

Open **Academics → Setup & Structure → Subjects** and add the subjects your school offers (Mathematics, English, Biology, and so on). Subjects are later attached to assessments and report cards.

## 4. Classrooms

Open **Academics → Setup & Structure → Classrooms** and add physical rooms (Lab 1, Block A Room 3). Classrooms are used by timetables and scheduling.

Once these exist you can enrol students, design ID cards, set up fee structures, and start capturing assessments.
