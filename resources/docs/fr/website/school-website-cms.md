# Créez et publiez le site Web de votre école

Chaque école de la plateforme dispose d'un site Web public. Le module **Site Web** est le système de gestion de contenu derrière celui-ci — aucun codage n'est requis.

## 1. Modèles et conception

Ouvrez **Site Web → Modèles et conception → Modèles et conception** (le hub). De là, vous pouvez :

- **créer**, **dupliquer** et **supprimer** des modèles de sites nommés
- définir le **modèle actif** pour votre site en ligne
- ouvrez le **Design Studio** pour un travail de conception avancé
- ouvrez le **Content Manager** pour modifier ce que dit le site

L'onglet **Sites Web** contient l'enregistrement du site lui-même :

- **Galerie de modèles** / **modèle actif**
- **Police** et **couleurs primaires/secondaires**
- **Suffixe du titre SEO** — ajouté aux titres des pages pour les moteurs de recherche

Choisissez un modèle qui correspond au caractère de votre école, puis ajustez les couleurs à votre marque.

## 2. Pages

Ouvrez **Site Web → Modèles et conception → Pages**. Chaque page contient :

- **Titre** et **slug** — le slug est l'adresse Web de la page, alors gardez-le court et stable
- Bouton **Publié** : les pages non publiées sont masquées sur le site public.
- Bascule **Page d'accueil** : exactement une page doit être la page d'accueil
- **Site Web** – à quel site appartient la page

Utilisez **Visual Editor** sur une page pour organiser son contenu ou modifiez le contenu via le gestionnaire de contenu.

## 3. Contenu

Ouvrez **Site Web → Modèles et conception → Gestionnaire de contenu**. Il modifie les **blocs de contenu** à l'intérieur du modèle actif (titres, texte, images, étiquettes d'appel à l'action et collections de cartes) tandis que la conception reste verrouillée. Cela signifie que le personnel peut mettre à jour le message sans en altérer la mise en page.

Téléchargez des images directement depuis l'outil là où un bloc en attend une.

## 4. Publier

1. Assurez-vous que les pages souhaitées sont **Publiées**.
2. Confirmez que la page d'accueil est marquée.
3. Vérifiez le site dans un navigateur – utilisez l’aperçu lorsqu’il est disponible et testez sur un téléphone.

Votre page d'admission (`/apply-online`), vos coordonnées et vos annonces sont toutes en direct sur ce site. Les familles arrivant de la recherche ou des médias sociaux atterrissent ici en premier, alors gardez les dates des trimestres et les coordonnées à jour.

> Modifiez le **slug** d'une page en ligne uniquement lorsque vous le devez : les anciens liens cesseront de fonctionner. Préférez éditer le titre et le contenu.
