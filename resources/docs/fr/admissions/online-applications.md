# Recevoir et traiter les candidatures en ligne

Chaque site scolaire construit sur la plateforme comprend une page publique **Postuler en ligne**. Les familles y déposent des candidatures ; votre personnel les examine dans l’espace de travail.

## 1. La page de candidature publique

Sur le site Web de votre école, la page d'admission se trouve à `/apply-online`. Les candidats remplissent leurs coordonnées et téléchargent les documents dont vous avez besoin, puis soumettez.

Vous pouvez personnaliser le formulaire d'admission et les documents requis sous **Admissions → Paramètres d'admission** dans l'espace de travail.

## 2. Examinez les candidatures reçues

1. Ouvrez **Admissions → Candidatures** dans la barre latérale de l'espace de travail.
2. Les nouvelles candidatures apparaissent dans la liste avec leur statut.
3. Ouvrez une application pour voir la soumission complète et les documents téléchargés.

## 3. Admettre l'étudiant

Depuis la candidature, vous pouvez admettre le candidat. L'admission crée le dossier de l'étudiant — l'étudiant apparaît ensuite sous **Étudiants** avec l'année universitaire, le formulaire et le volet reportés de la candidature, le cas échéant.

## 4. Facturez les frais

Après l'admission, passez à **Finance → Facturation et revenus des étudiants → Factures** et créez la facture (individuellement ou avec le moteur de facturation automatique — voir [Facturation](/docs/finance/fee-structures-and-invoicing)).

## Statuts de candidature que vous verrez

Les candidatures sont soumises, en cours d'examen et admises (et rejetées le cas échéant). Ouvrez toujours l'enregistrement plutôt que de vous fier uniquement à la couleur de la liste : la vue détaillée complète montre tout ce qui a été soumis.
