# Créer des structures de frais et émettre des factures

La facturation des frais dans l'espace de travail comprend deux parties : les **structures de frais** (ce que doit chaque formulaire ou note) et les **factures des étudiants** (la facture réelle par étudiant). Les deux se trouvent sous **Finance → Facturation et revenus des étudiants**.

## 1. Structures tarifaires

1. Ouvrez **Finance → Facturation et revenus des étudiants → Structures de frais**.
2. Créez une structure : choisissez l'année universitaire, la forme/la note à laquelle elle s'applique et le montant.
3. Ajoutez des catégories de frais (frais de scolarité, prélèvements, activités) si vous détaillez les frais : les **Catégories de frais** font partie du même groupe.

Les structures pilotent le moteur de facturation automatique et le sélecteur de frais du formulaire de facture.

## 2. Émettez une facture manuellement

1. Ouvrez **Finance → Facturation et revenus des étudiants → Factures**.
2. Cliquez sur **Créer**.
3. Choisissez l'**étudiant**, l'**année universitaire** et le **terme**. Le formulaire filtre les structures tarifaires disponibles selon celles correspondant à l'année de l'étudiant et à l'année sélectionnée.
4. Sélectionnez les structures tarifaires à inclure. Les totaux sont calculés automatiquement ; une dispense de frais (si configurée) s'applique sous forme de réduction.
5. Sauvegarder. La facture est créée avec le statut **Impayé** et un numéro de facture unique.

## 3. Exécutez le moteur de facturation automatique

Pour toute une cohorte à la fois :

1. Dans le tableau des factures, cliquez sur **Exécuter le moteur de facturation automatique**.
2. Choisissez l'objectif de facturation (qui forme/grades et terme).
3. Le moteur crée des factures pour chaque étudiant éligible qui n'a pas encore de facture ouverte pour cette portée.

C'est le moyen le plus rapide de facturer un groupe annuel le premier jour du trimestre.

## 4. Documents

Chaque facture peut être imprimée (**Imprimer la facture** sur la ligne). La mise en page des factures et des reçus (logo, couleurs, canaux de paiement, notes d'accroche) est contrôlée sous **Finance → Comptabilité de base et configuration → Modèles de documents**.

## 5. Acceptez les paiements

Enregistrez les espèces, les virements et l'argent mobile sur la facture et imprimez les reçus — voir [Enregistrer les paiements] (/docs/finance/recording-payments). Les familles peuvent également payer via **Pay via Paynow** et soumettre des **Preuves de paiement** pour votre approbation.
