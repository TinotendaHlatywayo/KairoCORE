# Gérer les dossiers des étudiants

La section **Étudiants** est la source unique de vérité pour chaque étudiant inscrit.

## Trouver un étudiant

Ouvrez **Étudiants** et utilisez le champ de recherche ou les filtres du tableau :

- Filtrez par **Forme/Note** pour voir tout le monde dans un niveau.
- Recherchez par nom, numéro d'admission ou numéro d'identification d'étudiant.

## Afficher un enregistrement

Cliquez sur une ligne d'étudiant pour ouvrir son profil. Il montre :

- **Données personnelles** — photo, noms, carte d'étudiant, numéro d'admission, sexe, date de naissance, e-mail, téléphone.
- **Inscription actuelle** — année universitaire, formulaire/grade et filière/classe. Ces valeurs proviennent de l'inscription de l'étudiant, elles reflètent donc toujours le placement réel, et non des copies obsolètes sur la ligne des étudiants.

## Édition

Cliquez sur **Modifier** sur n'importe quel enregistrement pour mettre à jour les coordonnées, la photo ou d'autres champs. Pour déplacer un étudiant vers un autre formulaire ou filière, modifiez les champs d'inscription (année scolaire, formulaire, filière) et enregistrez.

## Suppression

La suppression est disponible depuis la table actions. Supprimez uniquement les dossiers créés par erreur. Pour les étudiants historiques, conservez le dossier afin que leurs frais, leurs présences et leurs bulletins restent liés.
