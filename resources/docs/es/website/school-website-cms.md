# Crea y publica el sitio web de tu escuela

Cada escuela en la plataforma tiene un sitio web público. El módulo **Sitio web** es el sistema de gestión de contenidos que lo respalda: no se requiere codificación.

## 1. Plantillas y diseño

Abra **Sitio web → Plantillas y diseño → Plantillas y diseño** (el centro). Desde aquí puedes:

- **crear**, **duplicar** y **eliminar** plantillas de sitio con nombre
- configure la **plantilla activa** para su sitio activo
- abra **Design Studio** para trabajos de diseño avanzados
- abra el **Administrador de contenido** para editar lo que dice el sitio

La pestaña **Sitios web** contiene el registro del sitio en sí:

- **Galería de plantillas** / **plantilla activa**
- **Fuente** y **colores primarios/secundarios**
- **Sufijo de título SEO**: añadido a los títulos de las páginas para motores de búsqueda

Elija una plantilla que coincida con el carácter de su escuela y luego ajuste los colores a su marca.

## 2. páginas

Abra **Sitio web → Plantillas y diseño → Páginas**. Cada página tiene:

- **Título** y **slug**: el slug es la dirección web de la página, así que mantenlo breve y estable.
- Alternancia **Publicado**: las páginas no publicadas están ocultas del sitio público
- **Alternar página de inicio**: exactamente una página debe ser la página de inicio
- **Sitio web**: a qué sitio pertenece la página

Utilice **Visual Editor** en una página para organizar su contenido o editar el contenido a través del Administrador de contenido.

## 3. Contenido

Abra **Sitio web → Plantillas y diseño → Administrador de contenido**. Edita los **bloques de contenido** dentro de la plantilla activa (títulos, texto, imágenes, etiquetas de llamado a la acción y colecciones de tarjetas) mientras el diseño permanece bloqueado. Eso significa que el personal puede actualizar el mensaje sin alterar el diseño.

Cargue imágenes directamente desde la herramienta donde un bloque espera una.

## 4. Publicar

1. Asegúrese de que las páginas que desea estén **Publicadas**.
2. Confirme que la página de inicio esté marcada.
3. Consulte el sitio en un navegador; utilice la vista previa cuando esté disponible y pruébelo en un teléfono.

Su página de admisiones (`/apply-online`), los detalles de contacto y los anuncios se encuentran en este sitio. Las familias que llegan desde la búsqueda o las redes sociales llegan aquí primero, así que mantenga actualizadas las fechas del semestre y la información de contacto.

> Cambie el **slug** de una página activa solo cuando sea necesario: los enlaces antiguos dejarán de funcionar. Prefiere editar el título y el contenido.
