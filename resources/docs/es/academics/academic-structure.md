# Configura tu estructura académica

Antes de inscribir estudiantes o obtener calificaciones, debe existir la estructura académica de su escuela. Todo lo que hay en el espacio de trabajo (inscripciones, horarios, boletas de calificaciones) hace referencia a estos registros.

Toda la configuración a continuación ocurre en la sección **Academics** de la barra lateral del espacio de trabajo, en el grupo **Configuración y estructura**.

## Orden de operaciones

1. Año académico (con términos)
2. Formularios/calificaciones (con secuencias de clases)
3. Materias
4. Aulas

Créelos en este orden: cada paso hace referencia a los registros creados antes.

## 1. año académico

Abra **Académicos → Configuración y estructura → Años académicos** y cree el año actual (por ejemplo, `2026`). Cada año académico contiene los términos o semestres que impartes. Los estudiantes están inscritos *en* un año académico, así que créelo primero.

## 2. Formularios o calificaciones

Abra **Académicos → Configuración y estructura → Nivel** y cree sus cursos; estos representan formularios o calificaciones (por ejemplo, formulario 1, formulario 2, grado 7). Mientras crea uno, puede agregar sus **transmisiones de clase** (por ejemplo, A y B) directamente en el mismo formulario utilizando el repetidor de transmisiones.

## 3. Sujetos

Abra **Académicos → Configuración y estructura → Materias** y agregue las materias que ofrece su escuela (Matemáticas, Inglés, Biología, etc.). Posteriormente, las materias se adjuntan a las evaluaciones y boletas de calificaciones.

## 4. Aulas

Abra **Académicos → Configuración y estructura → Aulas** y agregue salas físicas (Laboratorio 1, Bloque A, Sala 3). Las aulas se utilizan por horarios y programación.

Una vez que existan, podrá inscribir estudiantes, diseñar tarjetas de identificación, configurar estructuras de tarifas y comenzar a capturar evaluaciones.
