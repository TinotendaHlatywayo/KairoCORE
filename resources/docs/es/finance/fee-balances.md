# Seguimiento de los saldos de las cuotas de los estudiantes

Cada factura tiene un **saldo** activo: el monto aún adeudado después de todos los pagos registrados.

## En la mesa de facturas

Abra **Finanzas → Facturación e ingresos de estudiantes → Facturas**. Cada fila muestra el total de la factura y el **Saldo** (resaltado en rojo cuando aún se debe dinero). Filtre la tabla para encontrar a todos los que tengan un saldo pendiente o busque una familia.

## En el panel financiero

Abra **Finanzas → Panel y análisis → Descripción general** para obtener una imagen de toda la escuela: totales facturados, cobrados y pendientes en los filtros actuales, con gráficos de tendencias. **Estados financieros** en el mismo grupo proporciona la vista del libro mayor.

## para una familia

1. Abra la factura del estudiante.
2. Haga clic en **Imprimir estado de cuenta** para obtener un historial de pagos completo: facturas emitidas, pagos recibidos y saldo final.

Este es el documento que debe entregarle a un padre, patrocinador o agente que pregunta "¿qué debemos todavía?"

## Lidiar con los atrasos

- Utilice la lista de facturas filtrada para facturas impagas para ejecutar una semana de cobro.
- Las declaraciones brindan a las familias un registro oficial claro, mucho más efectivo que un recordatorio verbal.
- Si una familia realmente no puede pagar, aplique una **Exención de tarifa** o utilice **Ajuste de tarifa** en la factura; nunca borre el historial de pagos.
