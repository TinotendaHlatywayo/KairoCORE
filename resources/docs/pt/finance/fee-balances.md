# Acompanhe os saldos das taxas estudantis

Cada fatura traz um **saldo** ativo — o valor ainda devido após todos os pagamentos registrados.

## Na tabela de faturas

Abra **Finanças → Faturamento e receita do aluno → Faturas**. Cada linha mostra o total da fatura e o **Saldo** (destacado em vermelho quando o dinheiro ainda é devido). Filtre a tabela para encontrar todos com saldo pendente ou pesquise uma família.

## No painel financeiro

Abra **Finanças → Painel e análises → Visão geral** para ver o panorama de toda a escola: totais faturados, coletados e pendentes nos filtros atuais, com gráficos de tendências. **Demonstrações Financeiras** no mesmo grupo fornece a visão do razão.

## Para uma família

1. Abra a fatura do aluno.
2. Clique em **Imprimir extrato** para obter um histórico completo de pagamentos: faturas emitidas, pagamentos recebidos e saldo final.

Este é o documento que deve ser entregue a um pai, patrocinador ou agente que pergunte "o que ainda devemos?"

## Lidando com atrasos

- Use a lista de faturas filtrada para faturas não pagas para executar uma semana de cobrança.
- As declarações proporcionam às famílias um registo oficial e claro – muito mais eficaz do que um lembrete verbal.
- Se uma família realmente não puder pagar, aplique uma **Isenção de Taxa** ou use **Ajuste de Taxa** na fatura; nunca exclua o histórico de pagamentos.
